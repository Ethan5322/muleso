MuleSoo Logo - PNG Export

To export as PNG, use one of these tools:

Quick Online Tools (No Installation):

  • CloudConvert: https://cloudconvert.com/svg-to-png
    - Upload: /public/mulesoo-logo-new.svg
    - Select PNG format
    - Enable transparent background
  • Online-Convert: https://image.online-convert.com/convert-to-png
    - Upload SVG file
    - Download as PNG
  • Convertio: https://convertio.co/svg-png/
    - Drag & drop SVG
    - Download PNG with transparency

Professional Options:

  • Adobe Illustrator: Open SVG → Export as PNG (8-bit with transparency)
  • Figma: Import SVG → Export as PNG at 4x resolution for crisp quality
  • Inkscape (Free): https://inkscape.org
    - Open SVG file
    - File → Export As → PNG Image

Recommended Settings for PNG Export:

  • Resolution: 1024x1024px (or 2048x2048px for high-res)
  • Background: Transparent
  • Format: PNG-24 (supports full transparency)
  • DPI: 300 (for print)

SVG Advantages (Use directly):

  • ✅ Always transparent background
  • ✅ Scalable to any size without quality loss
  • ✅ Smallest file size
  • ✅ Works in all modern browsers
  • Perfect for web, email, and digital use

# Telga Portfolio Concept

A fourth portfolio card, materially different from the other three added in
[[Added Three Portfolio Projects]]: those three are real, existing projects
with actual code on Desktop. **Telga has no folder, no repo, no code.** It is
a new venture concept the user described directly in chat, and the card is
built and labelled accordingly — `upcoming: true`, framed as a positioning
idea, not a built product.

## What it is

An airtime and bill-payment vending network for Ethiopia, using the same
networked-reseller model that made **Flash** and **Kazang** (the user wrote
"Kazan," a near-certain reference to Kazang) ubiquitous across South African
informal retail: a small shop owner becomes a vending agent with a POS
terminal or an Android phone, sells airtime/electricity/bill payments to
walk-in customers, earns a commission per sale, carries no stock.

## Honesty boundary held here

Every field describing Telga is written at the same tier as the other
concept-stage card already in this portfolio, `DR. Hospital — AI Clinic
System` — `result:
'Upcoming — in active development'`, a `tech` array stating an *intended*
stack rather than a built one, and no `client` name implying a real signed
customer. The description explicitly credits Flash/Kazang as the proven model
being adapted, rather than implying MuleSoo built or is affiliated with
either — Telga is a new idea, not a claimed clone.

## The cover

Confirmed on Desktop first: no `Telga` folder exists anywhere, so there was
no real screenshot or asset to build from — this cover is a designed mockup,
same treatment `scripts/make-portfolio-covers.cjs` gives every other
concept-stage card.

First version showed a slim phone-like screen. The user's direction: it
should look like "a new Flash swiping machine, but yellow" — a real
handheld card terminal, not an app on a phone. Redesigned around that
silhouette: molded yellow plastic body, a recessed swipe slot with a card
mid-drag through it, a small dark screen, and a physical keypad below —
the details that read as "device" rather than "screenshot."
